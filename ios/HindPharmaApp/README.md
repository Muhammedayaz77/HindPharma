# Hind Pharma iOS

Native iOS application for Hind Pharma.

## Architecture

- Swift
- SwiftUI
- MVVM
- `View/` for UI
- `ViewModel/` for presentation state and actions
- `Models/` for domain/data models
- `Helper/` for platform utilities
- `Assets/` for iOS-only application assets

This application is independent from the web and Android implementations.
