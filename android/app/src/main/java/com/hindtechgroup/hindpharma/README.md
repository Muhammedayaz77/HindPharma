# Hind Pharma Android

Native Android application for Hind Pharma.

## Architecture

- Kotlin
- Jetpack Compose
- MVVM
- `View/` for UI
- `ViewModel/` for presentation state and actions
- `Models/` for domain/data models
- `Helper/` for platform utilities
- `Assets/` for Android-only application assets

This application is independent from the web and iOS implementations.
